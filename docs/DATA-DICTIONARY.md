# 数据定义

- `scans.csv` 每行一个收件。`event` 和 `tag` 是保形字符串，`flight` 为机场航班号，`leg_hint` 为可空精确航段。`action` 取 `SORT`、`LOAD`、`OFFLOAD`。`effective` 与 `received` 为带偏移 ISO 8601，后者不能早于前者。UTC 精度微秒。原因码同 `app/reasons.py`。
- `legs.csv` 含唯一 `leg`、`flight`、`start`、`end`、`destination`。窗口 `[start,end)`，用 UTC 比较。存在明确提示时仍须命中时间和航班。无提示且有多候选时隔离。`manifest.csv` 每个 `tag` 只出现一次且 `planned` 必须引用已知 `leg`。
- `retags.csv` 为可选换牌单，列 `old_tag,new_tag,effective`（带偏移时刻）。空文件或未提交按无换牌处理；仅表头按既有 `HEADER_ONLY` 失败。旧牌、新牌各自全单唯一，新旧不得相同；新牌不得同时出现在 `manifest.csv`，否则以 `RETAG_PLAN_CONFLICT` 拒绝（换牌会让同一实物被新旧牌各计一件，虚增待证）。同旧牌二次换牌（换牌链）以 `RETAG_CHAIN` 拒绝。缺字段或坏时刻行隔离不影响其余换牌。
- 换牌身份在航段关联之后、回放之前解析，按生效时刻切分，全程保留扫描原牌与换牌单原行号：旧牌扫描生效早于换牌归原实物（晚到撤下按生效时刻仍算回原件），不早于换牌则视为旧牌另发的独立实物（`TAG_REISSUED`，禁止并入新牌实物的装机）；新牌扫描生效不早于换牌归换牌实物，早于换牌整行隔离为 `RETAG_ANCHOR`，归属存疑、不计末态，可凭原行号查扫描原件。回放以「实物件 + 航段」为键，迟到高水位与同刻冲突规则不变。
- 原件只接受 UTF-8，可带 BOM。物理起始行号保留。重复表头计分段，空行单计，宽度不符保留整行。空文件、全空记录、仅表头分别有明确失败。`-`、`N/A`、`NULL`、`未知` 与空串都不参与必填匹配。API 中被归一化的可选提示用 `null` 表示缺提示。
- 同扫描编号按航段提示、航班、动作、行李牌和生效时刻比较。内容相同取最早收件，内容矛盾整组隔离。不同编号同牌同航段同刻同动作只改变一次状态。收件决定迟到标记，生效决定回放。同刻相反装撤产生冲突，后续有效动作可确认新末态。
- 对账按实物计件，不按牌计件：清单件映射到换牌后的实物，`pieces` 为全部实物数，`retagged` 为其中持换牌单的件数；计划段装载且无未决装撤及错装时计已装。计划段末态撤下计明确未装。其他计划件待证。错载按非计划段末态装载记录，按实物去重计件。清单外行李（含换发后旧牌对应的另一件）另外列出。列宽失配行只提供原始字段，不对其牌号做确定归属。
- 批次由规则版本与全部提交文件（含换牌单）内容哈希决定。SQLite 一次提交原件和结果；同源并发使用唯一键，复算比较结果散列。换牌单补到后内容哈希变化即生成新批次，同批重跑命中唯一键、复用归档，不重复记件。证据签发核对摘要及守恒，归档原样含 UTF-8 BOM。
